| Signification | Web vérifié = ticker retrouvé textuellement dans une source publique (pas testé dans un Terminal actuel). |
| Signification | Document uniquement = présent dans le document de travail mais aucune corroboration publique trouvée pendant cette recherche. |
| Signification | Lacune identifiée = famille/zone à rechercher; aucun ticker supposé ou inventé. |
| Limite | Ce n’est PAS une liste exhaustive de Bloomberg. L’exhaustivité exige une recherche Terminal SECF/CTM/SPOT/CDAT/SRTE et validation des droits. |
| 1 / Recherche | SECF <GO> : rechercher par produit, région, type SPOT / futures / swaps / indices; exporter les résultats. |
| 2 / Contrats | CTM <GO> : filtrer Oil / Natural Gas, bourse, région; récupérer les contrats et generic 1. |
| 3 / Prix physiques | SPOT <GO> : inventorier les évaluations spot / PRA par bassin et Incoterm. |
| 4 / Contributions | CDAT <GO> : rechercher séries Platts / Argus; vérifier droits et disponibilité. |
| 5 / Fret | SRTE <GO> : recenser tarifs maritime tankers puis vérifier Bloomberg security IDs. |
| 6 / Validation | DES <GO> pour libellé complet, place, underlying, contrat, unité, devise, source primaire. |
| 7 / Export | Pour chaque ticker confirmé, extraire PX_LAST (quotidien) + dates; distinguer settlement, assessment, last. |
| 8 / Generic | Documenter CDEF / Generic Rolls ou metadata effective contract et dates de roll; exporter si possible contrat réel. |
| 9 / Licences | Confirmer entitlements et droit de stockage/restitution/usage applicatif avec Bloomberg. |
| 10 / Champs demandés | Ticker; Bloomberg ID (BBGID si dispo); name; security type; exchange; currency; unit; country/location; price field; availability start/end; roll; licensing. |
